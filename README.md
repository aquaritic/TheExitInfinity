# TheExitInfinity

The Exit ∞

A spinoff of the exit 8 video game, its based on memorizing colors rather then the original game which is more detailed. 
The game has been made intentionally simple, I just thought of a game idea and brought it to life in a minimalist way, might work on it more in the future by adding new anomaly types or progressive difficulity.

How to play: The first room upon loading will present you with 4 colored corners, you have to memorize those colors and their position, then when you press W it starts the game. You press W if you think there is an anomaly (a change in color, or in color position), and press S if you think nothing changed. The game is infinite and has no end unlike The Exit 8 and tracks statistics like rooms completed, accuracy, and how many correct/wrong decisions.

Controls if you didn't read above:

W - Safe, you think there is no anomaly, generates a new room
S - Unsafe, you think there is an anomaly, generates a new room

Both will update stats

The exit 8 summary so you can understand my game:

In the exit 8, the player is trapped in a subway and must memorize details like posters, etc 
once they enter a new hallway they have the choice to move forward or backward depending on if they think there is an anomaly present, 
if they fail to catch an anomaly they are sent back to start and must get 8 anomalies in a row to escape.
